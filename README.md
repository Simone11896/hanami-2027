# Hanami 2027 · Il fronte dei ciliegi

Sito statico per pianificare il viaggio in Giappone dal 29 marzo all'11 aprile 2027,
basato sulle date ufficiali di fioritura 2011–2026 (JMA) per 41 città e 24 luoghi di hanami.

## Pubblicazione con GitHub Pages
1. Crea un repository (es. `hanami-2027`) e carica `index.html`.
2. Vai su **Settings → Pages**.
3. In "Build and deployment" scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`, poi **Save**.
4. Dopo circa un minuto il sito è online su `https://<tuo-utente>.github.io/hanami-2027/`.

Il file è autonomo: dati, stile e codice sono tutti dentro `index.html`.
Serve internet solo per i caratteri tipografici (Google Fonts); senza, usa quelli di sistema.
